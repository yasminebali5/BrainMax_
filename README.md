# BrainMax Unified

Combined local Django prototype. Wafa's blue account interface and navigation frame Yasmine's six-question subject assessments, answer-key scoring, and results review. Brain is the strategic learning coach, paired with Pinky, an original supportive robot companion.

## Run locally

```bash
python3 -m venv .venv
.venv/bin/python -m pinky install -r requirements.txt
cp .env.example .env
# Set a random SECRET_KEY in .env. Add a Groq key to GROQ_API_KEY if AI chat is needed.
.venv/bin/python manage.py migrate
.venv/bin/python manage.py runserver 127.0.0.1:8080
```

Open http://127.0.0.1:8080. Create an account, complete Profile, and start Assessment. For a local demo account, run `.venv/bin/python manage.py seed_demo`.

ChromaDB keeps its local vector index in `.chroma/` by default. Set `CHROMA_DB_PATH` to a persistent local volume when running in a container or hosted environment.

## Languages and companion chat

- English is the default interface language. Choose English, French, or Arabic under Settings → Interface language; the selection is saved with the learner’s preferences. Arabic uses a right-to-left layout. Existing reviewed question-bank items and interface labels use offline translations; expanded scenario questions without a translation keep their original English text, while subject and topic labels remain localized.
- Brain and Pinky share a chatbot-style conversation. Messages are kept in the current browser session only, separately for each signed-in account in that browser, and can be removed with **Clear conversation**. They are not saved to the learner profile or RAG history.
- The **AI Coach** sidebar page follows the Amel branch's chat-and-insights layout. It answers learner questions with supportive responses and feedback grounded in completed practice; choose English or Tunisian Arabic for AI replies. When AI coaching is off or unavailable, clearly labelled local guidance remains available.
- When AI coaching is enabled, recent conversation turns may be sent to Groq (preferred when configured) or OpenRouter along with the other disclosed coaching context. AI responses are requested in the selected language. Local coach responses and assessment-mode support are available in French and Arabic without AI.

## Scoring and coaching

- Subjects: machine learning, cybersecurity, artificial intelligence. Six questions each, grouped into three two-question sections.
- Final score = correct answers without hints ÷ total × 100. Accuracy includes all correct answers. Calibration compares confidence with correctness. Time is recorded but never penalized.
- Brain gives field-by-field guidance during profile setup. After profile setup, learners complete the six-question baseline assessment; submitting its final answer automatically opens the learning path. During an active assessment, both companions stay in quiet mode and provide only neutral, content-free support; they never receive the answer key or correctness data. Scores, section statistics, explanations, and recommendations remain available from the Assessment page after completion.
- Brain gives professional, actionable coaching through Groq (`GROQ_API_KEY`, preferred) or OpenRouter only after the user enables **AI coaching** in Settings and the server has a provider key. Set `GROQ_MODEL` to override the default `llama-3.3-70b-versatile`; OpenRouter remains available as a fallback when no Groq key is configured. Otherwise the coach gives clearly labelled local guidance. During an active assessment, it never sends the question, answer key, or in-progress answers to the model.
- **Personal history memory** is a separate, off-by-default setting. When enabled, the account-scoped local ChromaDB index stores the learner's profile (name, subject, role, motivation, experience, study-time preference), goals, completed-assessment summaries, and completed learning-path results. It does not store passwords, email addresses, or raw answer keys. The Brain Twin retrieves this context for its memory panel; the coach can also use relevant retrieved history. Embeddings are computed locally and Chroma sends nothing by itself. Retrieved history is sent to the configured AI provider only when **AI coaching** is also enabled. Profile and goal edits refresh their memory record. Turning memory off removes the learner's vector records; deleting learning data removes both the Chroma records and account-linked assessment history. Export downloads all completed assessments and learning-path results.
- The learning path is an ordered, 10-step quest: sequence memory, a focus grid, concept matching, two subject-learning questions, and five cognitive games (Stroop, N-Back, Operation Span, Pattern Matrix, and Evidence Updating). All practice, matching, and cognitive-game questions use distinct subject-bank questions; matching no longer reuses practice or assessment questions. Each game has its own presentation: color-focused choices, flip-card recall, a branching answer diagram, a missing-piece puzzle, or an evidence-review chart. The first path is a balanced baseline. Later paths prioritize the relatively lower-scoring cognitive-game or subject-learning activity, comparing up to three completed paths when enough attempts exist; practice questions also start with the learner's lowest-scoring assessment topic. At least 70% is required to unlock the next step; matching offers six pairs and five correct matches meet that threshold. Each cognitive game presents up to ten server-scored trials. When the fresh question pool is smaller, trial counts are shortened and distributed across all five games; scores remain the accuracy across the trials presented. Cognitive-game questions are drawn from a reviewed, subject-specific pool, with distinct questions across all five games. Questions shown in prior activities and assessment items are excluded from later challenges and retries; questions in locked, unshown activities do not count as seen. An incorrect answer shows the correct answer and explanation; Pinky takes responsibility for unclear wording. Every attempt score, elapsed time, and coaching note is saved. Brain gives a practical strategy before each activity and specific next-step guidance after every attempt. Pinky adds encouragement after a retry is needed. The final score is the average of all 10 passing scores; total time includes retries and is reported separately. Score, time, challenge, topic, and pass status go to the configured AI provider only when AI coaching is enabled; otherwise clear local guidance is shown. With **Personal history memory** enabled, the completed result and learning-only attempt details are saved to the learner's private local RAG memory. Progress, scores, times, and coaching feedback are included in data exports. Assessment difficulty is selected per topic from profile experience and previous topic results, while preserving section balance and avoiding unseen-question repeats where possible. Learning-path priorities and challenge levels evolve after each completed assessment; levels are provisional practice choices, not ability labels.
- Five domain-aware cognitive-game paradigms are integrated into the 10-step learning path, alongside five subject-practice activities. Their trials are graded and persisted server-side, contribute to pass status and the final quest average, and use the learner's assessed concepts in their prompts and stimuli. Pattern Matrix presents its subject question as a fill-the-missing-piece puzzle with selectable answer tiles. These are adapted practice activities, not validated cognitive measures. Cognitive games removed to meet the 10-activity limit are archived out of existing paths without deleting their saved attempt history. The path also includes Heba's reviewed subject exercises, scored and reviewed server-side with a pass/status summary and answer explanations. With **AI coaching** enabled and a provider configured, the app can instead generate six fresh multiple-choice variants using the reviewed examples and assessment topics as context. Generation sends only the subject, topics, requested language, and reviewed examples—not the learner profile or assessment answers. Generated questions are validated before use; provider or invalid-response errors are shown rather than silently replaced. AI exercise text is not stored as a reviewed example.
- Brain Twin shows the chronological practice record, score curve, topic radar, and a 12-week completed-session heatmap. Its animated robot presents the learner's current name, subject, score, and goal; with **Personal history memory** enabled, an account-scoped Chroma RAG lookup displays the profile and progress context recalled for that learner. Learners can set a target score, target date, and weekly session goal; the dashboard tracks latest-score progress and completed practice days without presenting goals or forecasts as guarantees. Export includes profile, goals, preferences, and completed assessments.
- The **AI Collaboration Score** appears on the dashboard and learning path as a provisional, unvalidated results summary. It shows the weighted results for clarification (20%), critical verification (25%), iteration (20%), autonomy (20%), and responsible use (15%). The final score is the weighted mean, rounded to the nearest integer; autonomy blends the recorded reflection equally with the latest assessment's unhinted-answer rate when available. This is a design proposal, not a validated measure or ability rating; conversation text is not retained or analyzed for the metric.
- Its next-practice projection includes an uncertainty range and confidence label, including a wide, very-low-confidence range from a single session; it is never a certainty or measure of ability.
- The reviewed question pools contain at least 128 distinct questions per subject. Each six-question session includes two items per section; question sets are randomized to avoid identical sets across learners while possible, and each learner sees no repeats within a section until that section's pool is exhausted. Definitions are available for a learner's selected choices after the assessment and adapt to the profile's experience level.
- Brain provides a provisional next-practice projection after a completed session. Its uncertainty range widens when evidence is limited; projections are not promises or predictions of ability. The **Share progress history with AI coach** setting controls whether recent scores may be sent to the AI coach when AI coaching is also enabled; Brain Twin history remains visible locally.
- Brain and Pinky use an original strategist/supporter dynamic and original CSS robot art. Voice uses the browser's speech synthesis with different pitch and pacing settings for each companion; it is off by default and is not a voice imitation. Mood check-in is optional self-report; Pinky responds only to the mood the learner selects, which is not inferred or saved. While a mood is selected, it is included as context in coaching requests only if AI coaching is enabled; otherwise the local response handles it. Preferences and learning data are linked to the account; Settings offers export and deletion.

The 4K transparent robot sprite sheets are `static/assets/bolt-sprites-4k.png` and `static/assets/bolt-growth-4k.png`. These are raster assets designed for sprite use and simple vector tracing, not native vector files.

This is a learning prototype, not a validated cognitive or medical measure. Each session samples only two items per section, and questions can repeat after a learner has seen that section's reviewed pool. Do not interpret small score changes as general ability changes.
