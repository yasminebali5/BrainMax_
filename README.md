# BrainMax Unified

Combined local Django prototype. Wafa's blue account interface and navigation frame Yasmine's six-question subject assessments, answer-key scoring, and results review. Brain is the strategic learning coach, paired with Pinky, an original supportive robot companion.

## Run locally

```bash
python3 -m venv .venv
.venv/bin/python -m pinky install -r requirements.txt
cp .env.example .env
# Set a random SECRET_KEY in .env. Add a Groq key to GROQ_API_KEY if AI chat is needed.
.venv/bin/python manage.py migrate
.venv/bin/python manage.py runserver 127.0.0.1:8080
```

Open http://127.0.0.1:8080. Create an account, complete Profile, and start Assessment. For a local demo account, run `.venv/bin/python manage.py seed_demo`.

ChromaDB keeps its local vector index in `.chroma/` by default. Set `CHROMA_DB_PATH` to a persistent local volume when running in a container or hosted environment.

## Languages and companion chat

- English is the default interface language. Choose English, French, or Arabic under Settings → Interface language; the selection is saved with the learner’s preferences. Arabic uses a right-to-left layout. Existing reviewed question-bank items and interface labels use offline translations; expanded scenario questions without a translation keep their original English text, while subject and topic labels remain localized.
- Brain and Pinky share a chatbot-style conversation. Messages are kept in the current browser session only, separately for each signed-in account in that browser, and can be removed with **Clear conversation**. They are not saved to the learner profile or RAG history.
- The **AI Coach** sidebar page follows the Amel branch's chat-and-insights layout. It answers learner questions with supportive responses and feedback grounded in completed practice; choose English or Tunisian Arabic for AI replies. When AI coaching is off or unavailable, clearly labelled local guidance remains available.
- When AI coaching is enabled, recent conversation turns may be sent to Groq (preferred when configured) or OpenRouter along with the other disclosed coaching context. When asked why a learning-path exercise was assigned, the Coach receives the saved assignment decision and the current activity; the dated Brain Twin score and response-time curve is included only when **Share progress history with AI coach** is enabled. Explanations cite recorded evidence only and do not infer day-to-day changes from dates or sessions that are not in the data. AI responses are requested in the selected language. Local coach responses and assessment-mode support are available in French and Arabic without AI.

## Scoring and coaching

- Brain can navigate to the app's allowlisted pages when the learner explicitly asks (assessment, learning path, learning profile, account profile, settings, Brain Twin, coach, or dashboard). It cannot navigate to arbitrary URLs. Domain terms such as phishing map to their assessment subject (Cybersecurity). Exercise topic requests select a topic from the active subject's reviewed bank; the next assessment emphasizes that topic while retaining other topics. New item text and answer keys are not generated or edited by chat.
- Learners can ask Brain to open/start an assessment or learning path and to change the next assessment subject, difficulty/level (Foundation, Building, or Stretch), topic focus, or learning-path activity format. They can also name a custom study topic for a focused lesson in the next learning path; its practice and matching questions and cognitive activities follow that topic. If no topic is named, Brain asks what they want to learn instead of limiting them to the question-bank categories. Custom lessons require AI coaching and a configured provider; cybersecurity lessons are constrained to defensive awareness and controls. Learning-plan changes produce a signed preview and must be confirmed; they do not alter an active assessment, existing path, or saved score. A new learning path uses the subject and requested level from the assessment that creates it.
- For a specifically requested assessment topic outside the reviewed question bank, Brain can prepare six focused AI-generated questions (for example, password safety or phishing awareness) and route to the assessment after the learner confirms the plan. This requires AI coaching to be enabled and a configured provider. Cybersecurity generation is restricted to defensive awareness and controls; each question set is validated before use. A typed confirmation such as “yes, apply now” applies the immediately preceding supported preview; other unsupported requests remain advice-only and are never represented as completed actions.
- The Coach can also prepare confirmation previews for learning-profile edits, practice-goal updates, settings (AI coaching, local memory, voice, progress sharing, mood check-in, and interface language), and pausing/resuming an active assessment. It never submits assessment answers or completes learning-path activities for the learner. Data export is offered as a learner-clicked download; deleting learning data requires a separate, clearly labelled confirmation and leaves the sign-in account intact. Every action is restricted to this app's signed-in account and allowlisted destinations; unsupported or invalid requests do not change data.
- When a stable feed reuses too many questions, high scores with few hints trigger harder exposure; lower or mixed scores trigger a different practice strategy with fresh questions and no automatic difficulty increase.
- Subjects: machine learning, cybersecurity, artificial intelligence. Six questions each, grouped into three two-question sections.
- Final score = correct answers without hints ÷ total × 100. Accuracy includes all correct answers. Calibration compares confidence with correctness. Time is recorded but never penalized.
- Brain gives field-by-field guidance during profile setup. After profile setup, learners complete the six-question baseline assessment; submitting its final answer automatically opens the learning path. The companion chat on the active assessment page stays in quiet mode, while the separate AI Coach remains available for general questions and does not receive in-progress answers or assessment content from the application. During an active assessment, both companions stay in quiet mode except when the assessment detects a rapid-response window: at least three of the last five answers are faster than the reading-time/personal-baseline guard, plus a separate chance-accuracy, repeated/cyclic-answer, low-timing-variance, skipped-engagement, or distraction signal. High-accuracy fast responses and questions marked `quick_recall` are not flagged. Pinky delivers the first nudge without blocking; a persistent pattern can pause for a localized check-in. The five-item cooldown and three-intervention cap apply. Flagged responses are marked low-confidence and re-queued without lowering an ability estimate (this prototype computes none) or applying a score penalty; final score and topic metrics use reliable responses, with the reliable-response count and audit details shown in results. The provisional uncertainty multiplier is recorded, not presented as a validated ability estimate. Event handling is local and never sends assessment telemetry or answer keys to an AI provider. Learners can pause, retry the re-queued items, or end the session without penalty. Scores, section statistics, explanations, and recommendations remain available from the Assessment page after completion.
- Brain gives professional, actionable coaching through Groq (`GROQ_API_KEY`, preferred) or OpenRouter only after the user enables **AI coaching** in Settings and the server has a provider key. Set `GROQ_MODEL` to override the default `llama-3.3-70b-versatile`; OpenRouter remains available as a fallback when no Groq key is configured. Otherwise the coach gives clearly labelled local guidance. During an active assessment, it never sends the question, answer key, or in-progress answers to the model.
- When a learner asks about stagnating scores, the Coach receives Layer C's evidence-backed plateau decision when one is available. It explains the recorded difficulty or format adjustment, or suggests the recorded strategy change; it does not infer a plateau from a single or noisy result or claim that a future learning-path change has already happened.
- **Personal history memory** is a separate, off-by-default setting. When enabled, the account-scoped local ChromaDB index stores the learner's profile (name, subject, role, motivation, experience, study-time preference), goals, completed-assessment summaries, and completed learning-path results. It does not store passwords, email addresses, or raw answer keys. The Brain Twin retrieves this context for its memory panel; the coach can also use relevant retrieved history. Embeddings are computed locally and Chroma sends nothing by itself. Retrieved history is sent to the configured AI provider only when **AI coaching** is also enabled. Profile and goal edits refresh their memory record. Turning memory off removes the learner's vector records; deleting learning data removes both the Chroma records and account-linked assessment history. Export downloads all completed assessments and learning-path results.
- The learning path is a fixed-order, 10-step quest: sequence memory, a focus grid, concept matching, two subject-learning questions, and five cognitive games (Stroop, N-Back, Operation Span, Pattern Matrix, and Evidence Updating). Recommendations adapt topic, question selection, and difficulty without moving or replacing the activities. All practice, matching, and cognitive-game questions use distinct subject-bank questions; matching no longer reuses practice or assessment questions. Each game has its own presentation: color-focused choices, flip-card recall, a branching answer diagram, a missing-piece puzzle, or an evidence-review chart. Practice questions also start with the learner's lowest-scoring assessment topic. At least 70% is required to unlock the next step; matching offers six pairs and five correct matches meet that threshold. Each cognitive game presents up to ten server-scored trials. When the fresh question pool is smaller, trial counts are shortened and distributed across all five games; scores remain the accuracy across the trials presented. Cognitive-game questions are drawn from a reviewed, subject-specific pool, with distinct questions across all five games. Questions shown in prior activities and assessment items are excluded from later challenges and retries; questions in locked, unshown activities do not count as seen. An incorrect answer shows the correct answer and explanation; Pinky takes responsibility for unclear wording. Every attempt score, elapsed time, and coaching note is saved. Brain gives a practical strategy before each activity and specific next-step guidance after every attempt. Pinky adds encouragement after a retry is needed. The final score is the average of all 10 passing scores; total time includes retries and is reported separately. Score, time, challenge, topic, and pass status go to the configured AI provider only when AI coaching is enabled; otherwise clear local guidance is shown. With **Personal history memory** enabled, the completed result and learning-only attempt details are saved to the learner's private local RAG memory. Progress, scores, times, and coaching feedback are included in data exports. Assessment difficulty is selected per topic from profile experience and previous reliable, unhinted results, while preserving section balance and avoiding unseen-question repeats where possible. The app records the per-assessment topic/difficulty/format run length and item entropy; the six-question multiple-choice flow is capped at two consecutive items with the same topic and difficulty. A one-level or heavily repeated feed with steady high results is treated as insufficient challenge exposure—not a learner plateau—and triggers a difficulty/format change to collect better evidence.
- Plateau detection is deliberately conservative: it evaluates the latest five completed sessions for a subject only after at least 30 reliable answers, two difficulty tiers, sufficient distinct-item exposure, and low score variance. A linear-regression 95% Student-t slope interval must include zero; a separate 90% two-one-sided equivalence test must fit inside a ±3 percentage-point-per-session band. No trend is not assumed to be equivalence. Noisy flat results, insufficient exposure, and clear trends do not become learner plateaus. Per-topic profiles then diagnose comfort, frustration, skill gaps, disengagement, mastery, or an otherwise unexplained plateau. Layer C responds respectively with a difficulty/format change, a lower tier plus guided practice, weak-topic/strong-topic interleaving, shorter game rounds, stretch practice, or a new retrieval strategy. Fast-and-accurate results are protected from the disengagement diagnosis. Plateau interventions pause for three completed sessions before review; the next assignment logs pre/post score change, post-intervention slope, hint rate, response time, and active time, then escalates from strategy to another practice modality to an optional teacher/mentor suggestion if a plateau remains. The detector does not compute IRT/Elo ability or claim a validated confidence interval for ability; it records score-based uncertainty evidence and never penalizes ability. Learning-path priorities and challenge levels remain provisional practice choices, not ability labels.
- Assessment pushback is handled locally by Pinky before any AI-provider call. If the learner does not name an affected question range, Pinky asks once; without a range, the score and uncertainty remain unchanged. For a specific window, response-time spikes are compared with the learner's own prior assessment baseline where available, alongside tab-blur, inactivity, exposure, and accuracy-recovery signals. Missing telemetry is treated as unknown, not as evidence against the learner. Challenge quality uses specificity (35%), constructiveness (25%), calibration (25%), and timing (15%); credibility combines behavioral consistency (60%) and challenge quality (40%), with a slowly updated claim-reliability prior. Only disputed answers receive reduced update weights, and uncertainty widens only for that window. The stored score is never silently changed; the review records its quality, credibility, affected items, uncertainty multiplier, and AI stance-integrity status for transparency. A three-question fresh verification set prioritizes the disputed topics, becomes the latest result, and preserves the historical score. Its outcome resolves uncertainty and gradually updates the claim-reliability prior; starting and completing it earn iteration credit even when the original result is confirmed. Critical-verification credit is capped per challenge and halves on each later dispute. Three later clean completed sessions decay open-review uncertainty, while the review remains visible until verification resolves it. These signals are limited to telemetry the assessment collects and cannot establish why a disruption occurred.
- Five domain-aware cognitive-game paradigms are integrated into the 10-step learning path, alongside five subject-practice activities. Their trials are graded and persisted server-side, contribute to pass status and the final quest average, and use the learner's assessed concepts in their prompts and stimuli. Pattern Matrix presents its subject question as a fill-the-missing-piece puzzle with selectable answer tiles. These are adapted practice activities, not validated cognitive measures. Cognitive games removed to meet the 10-activity limit are archived out of existing paths without deleting their saved attempt history. The path also includes Heba's reviewed subject exercises, scored and reviewed server-side with a pass/status summary and answer explanations. With **AI coaching** enabled and a provider configured, the app can instead generate six fresh multiple-choice variants using the reviewed examples and assessment topics as context. Generation sends only the subject, topics, requested language, and reviewed examples—not the learner profile or assessment answers. Generated questions are validated before use; provider or invalid-response errors are shown rather than silently replaced. AI exercise text is not stored as a reviewed example.
- Brain Twin shows the chronological practice record, score curve, topic radar, and a 12-week completed-session heatmap. Its animated robot presents the learner's current name, subject, score, and goal; with **Personal history memory** enabled, an account-scoped Chroma RAG lookup displays the profile and progress context recalled for that learner. Learners can set a target score, target date, and weekly session goal; the dashboard tracks latest-score progress and completed practice days without presenting goals or forecasts as guarantees. Export includes profile, goals, preferences, and completed assessments.
- The **AI Collaboration Score** appears on the dashboard and learning path as a provisional, unvalidated results summary. It shows the weighted results for clarification (20%), critical verification (25%), iteration (20%), autonomy (20%), and responsible use (15%). The final score is the weighted mean, rounded to the nearest integer; autonomy blends the recorded reflection equally with the latest assessment's unhinted-answer rate when available. This is a design proposal, not a validated measure or ability rating; conversation text is not retained or analyzed for the metric.
- Its next-practice projection includes an uncertainty range and confidence label. Pinky only communicates the Brain Twin projection, leads with its range, and states its central estimate as uncertain. A single completed session is insufficient for a numeric projection; the existing range has no calibrated probability level or month-specific horizon, so Pinky does not invent either. The projection is never a certainty or measure of ability.
- The reviewed question pools contain at least 128 distinct questions per subject. Each six-question session includes two items per section; question sets are randomized to avoid identical sets across learners while possible, and each learner sees no repeats within a section until that section's pool is exhausted. Definitions are available for a learner's selected choices after the assessment and adapt to the profile's experience level.
- Brain provides a provisional next-practice projection after a completed session. Its uncertainty range widens when evidence is limited; projections are not promises or predictions of ability. Assessment pushback is scored as `0.6 × behavioral consistency + 0.4 × challenge quality`; missing telemetry is unknown (consistency `0.5`), and a dispute without a question window triggers one clarification before scoring. A question about a score does not create a dispute or update. The **Share progress history with AI coach** setting controls whether recent scores may be sent to the AI coach when AI coaching is also enabled; Brain Twin history remains visible locally.
- Brain and Pinky use an original strategist/supporter dynamic and original CSS robot art. Voice uses the browser's speech synthesis with different pitch and pacing settings for each companion; it is off by default and is not a voice imitation. Mood check-in is optional self-report; Pinky responds only to the mood the learner selects, which is not inferred or saved. While a mood is selected, it is included as context in coaching requests only if AI coaching is enabled; otherwise the local response handles it. Preferences and learning data are linked to the account; Settings offers export and deletion.

The 4K transparent robot sprite sheets are `static/assets/bolt-sprites-4k.png` and `static/assets/bolt-growth-4k.png`. These are raster assets designed for sprite use and simple vector tracing, not native vector files.

This is a learning prototype, not a validated cognitive or medical measure. Each session samples only two items per section, and questions can repeat after a learner has seen that section's reviewed pool. Do not interpret small score changes as general ability changes.

Learners can ask Brain to change the current learning-path topic directly. Confirmed topic changes keep the same activity order and mechanics, replace questions only in unfinished activities, archive their previous attempts, and leave the assessment unchanged; completed activities remain intact. The learning path also offers an explicit restart action: it archives the current activity scores/progress, starts the same ten activities over, and retains the selected topic when fresh questions are available. Reviewed topics use the existing question bank, while custom topics require AI coaching and a configured provider. Learning-path profiles report per-topic provisional estimates, uncertainty, topic-local difficulty targets, and separate per-topic plateaus and forecasts. The enlarged radar has a fixed topic order and polygon area is not a total score; per-topic values are also listed as text. A large difference becomes a persistent asymmetry only when the same pattern appears in two sessions. Unverified profiles remain provisional, and task difficulty is never selected from a global average. Current dimension evidence is topic-level assessment accuracy; the platform does not yet measure standalone attention or general cognitive ability.
